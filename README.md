#  Kebun Binar Bumi

Game match-3 dengan mode Kasual dan mode Target.
Selesaikan pesanan pelanggan, dapatkan uang, beli bibit dan perlengkapan, gunakan sihir Binar dan sihir Bumi untuk membantu selesaikan level.

Didedikasikan untuk Kebun Binar Bumi di Kabupaten Bogor.
